# Tests: three credential-free layers, then live

Run in this order after every regeneration; all must pass before commit.

**Offline validation** (`tests/offline_validation.mjs`): spawns `stackql exec` against the local file registry `{"url": "file://<abs>/provider-dev/openapi", "localDocRoot": "<abs>/provider-dev/openapi", "verifyConfig": {"nopVerify": true}}` with `--output json`. Assert: `SHOW SERVICES` count and names; `SHOW RESOURCES` per service (exact sorted lists); `SHOW METHODS` verbs and required params on representative resources; env-var behaviour (required param present with the variable unset, absent with it set); `DESCRIBE EXTENDED` columns (snake aliases present, camel names absent, wide flat configs, wrapped arrays, objectKey projections); that the flagship binding exists. Note `--output json` renders scalars as strings.

**Integration** (`tests/integration/`): an in-process `http` mock of the API serving the wire shapes the spec declares (bare arrays, envelopes, empty 2xx, the vendor's error body), enforcing the auth header (401 otherwise), echoing rate-limit headers, with mutable in-memory stores so lifecycles round-trip, and a request log (method, path, query, headers, body). The runner copies `provider-dev/openapi` to a gitignored `.registry-tmp`, rewrites every `servers[].url` (document and path-level) to the mock, preserves variables and `x-stackQL-envVar`, and spawns stackql **asynchronously** (a synchronous wait deadlocks the mock on the same event loop). Assert row-level results and wire calls per archetype: list wrap + single read, auth header + wrong-token 401, env-var resolution vs WHERE override vs unset failure, root-path overrides, INSERT/UPDATE/DELETE lifecycles with their exact bodies, every EXEC action, every transform (bare-array bodies, non-JSON responses), snake keys resolving to camel wire names, pagination over a two-page fixture, query-param pushdown, objectKey projections, the flagship, a 404. Keep `probe.mjs` (start mock, run ad-hoc SQL, print stdout/stderr and wire calls) - it is how bindings get debugged.

**Meta-route** (`bin/test-meta-routes.cjs` over `bin/start-server.sh` / `stop-server.sh`, pgwire-lite on port 5444, host `127.0.0.1`): walks every service, resource and method with `SHOW`/`DESCRIBE`. A resource with no columns or a service with no resources fails it - fix the mapping (skip-code, or inject a schema), never the test.

**Smoke** (`tests/smoke_test.py`, pystackql): `--live` switches from the local file registry to the published provider (post-publish verification); `--read-only`, `--cleanup-only`, and a flag for any gated expensive lifecycle. Design it from the vendor's Terraform provider examples - the resources and mutations people actually use - with a budget under $5 (aim under $1): read smokes across the surface, cheap self-cleaning write lifecycles (INSERT / SELECT / UPDATE / DELETE of a secret, key, small object), a config toggle-and-restore (which doubles as the UPDATE string-coercion probe), the flagship round trip, and the expensive create/delete only behind its flag. Serial pacing under the vendor's limit (`INTER_REQUEST_DELAY_S`); a 429 fails the run. Sweep `stackql-smoke-*` breadcrumbs first. Credentials from the environment exactly as the provider reads them; the harness upgrades pystackql's managed binary when older than the minimum the provider needs. Print a PASS/FAIL summary and exit non-zero on any failure.
